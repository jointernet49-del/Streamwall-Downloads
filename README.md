# StreamWall Downloads

StreamWall の配布ファイル置き場です。

## ダウンロード

最新版インストーラー:

https://github.com/jointernet49-del/Streamwall-Downloads/raw/main/StreamWallInstaller.zip

## 使い方

1. `StreamWallInstaller.zip` をダウンロードします。
2. zipを展開します。
3. `StreamWallSetup.exe` を実行します。
4. インストール先を選んでインストールします。

## メモ

- 初回インストールや入れ直しには `StreamWallInstaller.zip` を使います。
- すでにStreamWallを入れている場合は、アプリ内の「更新確認」から更新できます。
- 保存済みの配信URLは、更新しても残るようにしています。
